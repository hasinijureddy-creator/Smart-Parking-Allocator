ADSA

Algorithms and Data Structures used to understand efficient parking allocation.

🌳 AVL Tree

An AVL Tree is a self-balancing Binary Search Tree. It maintains balance after insertion and deletion.

Balance Factor = Height(Left Subtree) − Height(Right Subtree)
AVL Condition: -1 ≤ Balance Factor ≤ +1

Rotations: LL Rotation, RR Rotation, LR Rotation and RL Rotation.

⛰️ Heap

A Heap is a complete binary tree commonly used in priority queues and Heap Sort.

Parent(i) = ⌊(i − 1) / 2⌋
Left Child(i) = 2i + 1
Right Child(i) = 2i + 2
Heap Sort Time Complexity = O(n log n)

🔍 Searching

Linear Search → O(n)
Binary Search → O(log n)

🔄 Sorting

Bubble Sort → O(n²)
Selection Sort → O(n²)
Insertion Sort → O(n²)
Merge Sort → O(n log n)
Quick Sort → Average O(n log n)

🚗 ADSA in Our Project

ADSA concepts help us understand how parking slots can be searched, organized and selected efficiently. Searching, sorting, trees and heaps provide the algorithmic foundation for designing a smart parking allocation system.

DMGT

Discrete Mathematics concepts related to parking slots, zones, relationships and logical decisions.

🔢 Sets

Sets can represent groups of parking slots such as available slots and booked slots.

A ∪ B = Union
A ∩ B = Intersection
A − B = Difference
|A ∪ B| = |A| + |B| − |A ∩ B|

🔗 Relations

R ⊆ A × B
Number of Relations = 2^(|A| × |B|)

🧩 Functions

A function maps every element of a domain to exactly one element of the codomain.

f : A → B

🕸️ Graphs

Graphs can represent relationships and connections between parking zones or locations.

G = (V, E)
Sum of Degrees = 2|E|

🧠 Logic

AND → P ∧ Q
OR → P ∨ Q
NOT → ¬P
Implication → P → Q

🚗 DMGT in Our Project

DMGT concepts help represent relationships between vehicles, parking slots and zones. Sets can represent available and booked slots, while graphs and logic can represent connections and allocation conditions.
